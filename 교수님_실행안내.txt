[모임결정 웹 프로그램 실행 방법]

1. 이 압축파일을 원하는 폴더에 모두 압축 해제합니다.
2. 컴퓨터에 Python 3.11 이상이 설치되어 있어야 합니다.
   - 다운로드: https://www.python.org/downloads/
   - 설치할 때 "Add Python to PATH"를 체크합니다.
3. 폴더 안의 "실행하기.bat" 파일을 더블클릭합니다.
4. 최초 실행 시 필요한 패키지가 자동으로 설치됩니다.
5. 설치가 끝나면 웹 서버가 실행되고 브라우저에서
   http://localhost:5000 주소가 자동으로 열립니다.

[같은 공간에서 여러 기기로 시연하는 방법]

실행 창에 표시되는 http://192.168.x.x:5000 형태의 주소를
같은 Wi-Fi에 연결된 다른 노트북이나 휴대전화에서 열면 됩니다.
Windows 방화벽 확인 창이 나오면 개인 네트워크 접근을 허용합니다.

[공개 배포 웹사이트]

제출 문서에 별도로 기재된 Render 주소를 사용하면 코드 설치 없이
인터넷에 연결된 다른 컴퓨터나 휴대전화에서 바로 접속할 수 있습니다.

[종료 방법]

서버가 실행 중인 검은색 창에서 Ctrl+C를 누르거나 창을 닫습니다.

[참고]

- 로컬 실행 데이터는 같은 폴더의 team_rooms.db에 저장됩니다.
- Render 공개 사이트의 데이터는 PostgreSQL 데이터베이스에 저장됩니다.
- 로컬 실행과 Render 사이트는 서로 별도의 데이터를 사용합니다.
